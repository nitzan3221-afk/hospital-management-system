# Hospital Management System

Internal hospital management system: a Python (FastAPI) backend API and an Angular frontend
that let hospital staff view patients, track vitals / medications / doctor visits, and act on
that data according to their role.

> Work in progress — full documentation (architecture diagram, API usage, DB choice) will be
> added at the end of the feature branch.

## Quick start

```bash
docker compose up --build
```

- API: http://localhost:8000
- Interactive API docs (Swagger): http://localhost:8000/docs
- Health check: http://localhost:8000/api/health
